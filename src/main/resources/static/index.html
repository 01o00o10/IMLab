先理解：WebSocket 和 IM 协议是什么关系？

WebSocket 提供持久、双向的传输通道；IM 在通道之上定义登录、聊天、确认、心跳等业务消息。此处使用自定义 JSON，不使用 STOMP。

连接经过 HTTP Upgrade，成功响应为 101。浏览器 WebSocket API 无法直接读取握手响应头或底层帧；可在开发者工具 Network → WS 中查看。此页面观测的是应用层报文。

PING / PONG 是 JSON 应用心跳，不是 WebSocket 控制帧。示例使用 userId 演示身份绑定，不代表生产环境的身份认证。
